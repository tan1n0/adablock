摘要稳定性诊断与边界复核实验，独立于上一轮结果。
远端目录：/root/adablock_digest_stability_20261022_01

问题定位：
diagnose.py 记录原 SVD 与 FP32 Gram 的 query、排序分数、预算概率和选块轨迹。
trace_analysis.py 提取第一次分歧及对应块文本。
首次选块分歧发生于第 21 解码步、第 23 层、第 6 个 KV 头。
相同 query、相同预算（73 块），块 377 与 382 的分数边界翻转。
被换出的 377 包含 plight；但只修复这一次选块仍是 70 分，不能据此断言单一块独自造成掉分。
输出 token 第一次分歧在第 38 个 token；后续轨迹比较含状态漂移，不可当成同 query 下的直接摘要误差。

候选：
double：高精度 Gram，再转换回原特征精度；这道题仍 70 分。
qr：QR 降维后 SVD；这道题仍 70 分。
guarded：沿用快速摘要，在选块分数边界与预算 CDF 边界附近，使用原 FP32 SVD 复核并缓存。
score_guard 与 cdf_guard 均为 1e-4；不使用答案、任务类型、题目编号或指定块编号。
预算类别、目标总读取量、排序器/预算器权重、prompt、输出上限均不改。
每次生成拥有独立可变摘要，防止不同分支之间共享复核结果污染计时。
若反复修正仍不稳定，升级为该层完整 SVD 复核；多数情形只复核少量块。
这是经验数值保护，不是经过证明的所有输入误差界，不能宣称普遍逐位等价。

验证：
先复现掉分题，并用单次选块干预与边界复核区分因果链。
随后固定保护阈值，对上一轮 9 题 × S/A/B × 两个配额的 54 组完整回归。
参考输出来自上轮冻结记录；相同预填充与生成配置，掉分题的参考轨迹已重新生成并吻合。
另外选两道未用于前述诊断的 CWE，分别 8K/16K，B、25% 配额；同次共享预填充重跑原 SVD 与复核版。
新题按原数据顺序选择第一道未进入旧 smoke 集的题，未按答案或得分筛选。

时间口径：
guarded 的解码耗时包含在线 SVD 复核、缓存填充、额外排序和预算检查。
初始摘要时间很短，但不能忽略转移到解码阶段的复核成本。
主回归计时关闭 trace；诊断中原 SVD/Gram 的 decode_seconds 开启了 trace，不可直接当作性能对照。
端到端 = 共享预填充 + 初始摘要 + 完整解码（含复核）。本轮未做重复计时置信区间。

旧代码和结果只读；protocol.json 记录受保护文件哈希，完成后复核。
