# 外部实验归档

本目录收纳原先位于 /root/adablock_* 的 25 个实验目录及 2 个结果压缩包。

- code/：各实验的顶层 Python 和 Shell 脚本。完全相同的内容只保留一份；共享版本位于 code/shared/。不同内容的版本分别保留。
- runs/：实验原始目录中的数据、模型、日志、结果、说明、第三方源码和环境快照。目录名保持原样。顶层脚本入口是指向 code/ 的相对符号链接，便于按原目录查找。
- archives/：原先位于 /root 的两个结果压缩包。
- /root/adablock/tmp/experiments_manifest.json：临时迁移清单，记录运行目录和脚本的对应关系及校验值。

迁移时只移动目录和压缩包，不改动实验结果内容。10 个指向其他实验目录的绝对符号链接已改为相对链接。runs/ 和 archives/ 在 Git 中忽略；code/ 与本说明可纳入版本控制；迁移清单放在项目内的 tmp/。

## 运行注意

这些是历史实验快照。部分脚本在代码中写死了旧的 /root/adablock_* 绝对路径；因此直接重跑前需要将这些路径参数化，或者临时建立旧路径兼容链接。为保留与实验清单相符的源码哈希，本次迁移没有改写这些脚本。JSSA 的第三方源码与环境快照也按原样保留，没有跨依赖包去重。

后续新实验建议直接从主项目启动，把输出写入 runs/ 下的新目录，避免再次复制整套脚本。
